Première version de Kanji Flashcards pour Android 8 et versions suivantes.

- Révision hors ligne de 2 495 kanji, du JLPT N5 au N1, en français.
- Mode normal avec saisie d'une lecture et d'une signification.
- Mode facile avec quatre choix : français, rōmaji, kana ou mélange des formats.
- Toutes les lectures ou significations regroupées sur les boutons du mode facile.
- Bouton « Je ne sais pas » et affichage des corrections dans les deux modes.
- Progression avec le système Leitner, statistiques, recherche et filtres.
- Export et import de la progression en TSV, sans compte ni connexion réseau.

Télécharger `kanji-flashcards-0.1.0.apk` pour installer l'application. Le fichier `.sha256` permet de vérifier le téléchargement.

Si une version de test est déjà installée, exporter d'abord la progression dans « Sauvegarde et réglages », puis désinstaller cette version avant d'installer la release. Les versions de test et la release utilisent des clés de signature différentes. Importer ensuite la sauvegarde TSV pour retrouver sa progression.
